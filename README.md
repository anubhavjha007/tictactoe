# ❌ Tic-Tac-Toe Game ⭕

A simple, lightweight implementation of the classic **Tic-Tac-Toe** game built using HTML, CSS, and JavaScript.

---

## 🎮 How to Play

1. The game is played on a standard **3x3 grid**.
2. **Player 1** plays as **X** and **Player 2** plays as **O**. Players take turns clicking on empty squares.
3. The first player to get **3 of their marks in a row** (horizontally, vertically, or diagonally) wins the game!
4. If all 9 squares are filled and neither player has 3 in a row, the match ends in a **Tie**.
5. Click the **Restart / Reset** button at any time to clear the board and start fresh.

---

## ✨ Features

- **2-Player Local Gameplay:** Play with a friend on the same screen.
- **Instant Result Detection:** Automatically checks for wins or ties on every move.
- **Scoreboard / Status Display:** Shows whose turn it is and announces the winner.
- **Responsive Design:** Looks and works great on both desktop and mobile devices.

---

## 🛠️ Built With

* **HTML5** – Game structure
* **CSS3** – Layout, styling, and visual feedback
* **JavaScript** – Core game logic and interactivity

---

## 🚀 How to Run

1. Download or clone this repository to your computer.
2. Open the project folder.
3. Double-click **`index.html`** to open and play the game directly in any web browser!
